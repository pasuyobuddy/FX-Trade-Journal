Connect your MT5 account

The journal reads your trade history through MetaApi, a service that runs MT5 in the cloud for you. Use your investor (read-only) password: it can see trades but can't open or close them.

How to export your history from MetaTrader 5
  1. In MT5 desktop, open the Toolbox (Ctrl+T) and go to the History tab.
  2. Right-click inside the list, choose Positions view, then set the period to All History (or the range you want).
  3. Right-click again and pick Report → Open XML (MS Office Excel 2007) or HTML (Internet Explorer). Save the file.
  4. Click Import MT5 report above, or drag the file onto this page. You can import several files (one per account or per month); duplicate trades are skipped.

Strategy Tester reports from an Expert Advisor backtest work too, and so do CSV files with columns like Time, Symbol, Type, Volume, Price, Profit. Your files are read in this browser only and are never uploaded. Imported trades are remembered on this device.
